Fundamentos de CSS

Resumen de los temas 2.1 al 2.9

2.1 Estructura y sintaxis

CSS utiliza selectores, propiedades y valores para darle estilo a una página web.

selector {
    propiedad: valor;
}

h1 {
    color: teal;
    font-size: 2rem;
}

2.2 Tipos de incorporación de CSS

CSS interno

Se escribe dentro de la etiqueta style en el head.

<style>
    p {
        color: red;
    }
</style>
CSS externo

Se utiliza un archivo independiente con extensión .css.

<link rel="stylesheet"
href="estilos.css">
CSS en línea

Se agrega directamente en la etiqueta HTML.

<p style="color: red;">
    Hola
</p>

2.3 Indentación, herencia y comentarios

  • Indentación: permite organizar el código y facilitar su lectura.
  • Herencia: algunas propiedades, como color y font-family, pasan del elemento padre a sus hijos.
  • Comentarios: sirven para dejar notas dentro del código.
/* Comentario en CSS */

body {
    color: #333;
}

2.4 Niveles de especificidad

La especificidad determina qué estilo se aplica cuando existen varias reglas para un mismo elemento.

Selector Peso
Estilo en línea 1000
ID (#menu) 100
Clases y pseudo-clases 10
Etiquetas y pseudo-elementos 1

!important permite dar prioridad a una declaración, aunque es mejor evitar su uso innecesario.

2.6 Media Queries

Permiten cambiar los estilos de una página según el tamaño de la pantalla.

@media (min-width: 768px) {
    .caja {
        background: royalblue;
    }
}
Estás utilizando una pantalla menor a 768px. Estás utilizando una pantalla de 768px o más.

2.7 Pseudo-elementos

Permiten modificar partes específicas de un elemento sin necesidad de agregar más etiquetas HTML.

Texto con ::before

Texto con ::after

Texto con ::first-letter

p::before {
    content: "→ ";
}

p::after {
    content: " ✓";
}

p::first-letter {
    font-size: 2.5rem;
}

2.8 Pseudo-clases

Se utilizan para aplicar estilos dependiendo del estado o la posición de un elemento.

  • Primero (:first-child)
  • Segundo (:nth-child(even))
  • Tercero
  • Cuarto (:nth-child(even))
button:hover {
    background: teal;
}

li:first-child {
    font-weight: bold;
}

li:nth-child(even) {
    background: #eee;
}

2.9 Z-index

Esta propiedad permite controlar qué elemento aparece delante o detrás cuando varios elementos se superponen.

z-index: 1
z-index: 3
z-index: 2

La caja roja queda encima porque tiene un valor de z-index mayor.
